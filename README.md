# Лабораторная работа 1.5

## Взаимодействие с пользователем в JavaFX

### Цель работы

Реализовать взаимодействие пользователя с приложением JavaFX: обработку выбора элементов таблицы, добавление, редактирование и удаление объектов, создание диалогового окна и проверку пользовательского ввода.

### Задание

1. Реализовать реакцию на выбор элементов в таблице.
2. Добавить функциональность кнопкам `Add`, `Edit` и `Remove`.
3. Создать диалоговое окно для изменения информации об объектах.
4. Реализовать проверку пользовательского ввода.

### Предметная область

В качестве предметной области используется **электронный каталог книг**.

### Книга

Книга содержит следующие характеристики:

- Название
- Переплёт
- Издательство
- Год издания
- Жанр
- Автор

### Автор

Автор содержит:

- ФИО
- Телефон
- E-mail
- Рейтинг

### Используемые технологии
